How to use the color palette generator


  1. Press Space or click Generate to create a new palette.
  2. Click the lock icon on any color you want to keep, then generate again to change only the rest.
  3. Pick a style such as Analogous, Pastel or Dark UI from the menu to steer the results.
  4. Click a hex code to copy it, or use Export to get CSS variables, SCSS, Tailwind config, JSON or SVG.
  5. Save favorites with ♥ Save, or copy the Share link to send the exact palette to anyone.


Frequently asked questions


Is the palette generator free?
Yes. Every feature is free with no account and no limits, and palettes are generated in your browser.
How does Chroma pick colors that go together?
It builds palettes in the OKLCH color space, which matches how people perceive brightness and saturation, then applies harmony rules such as analogous, complementary or triadic so colors stay balanced.
Can I use these palettes commercially?
Yes. Anything you create is yours to use in any project, including client and commercial work.
How do I check my palette for color blindness?
Below every palette, Chroma shows how it looks with protanopia, deuteranopia, tritanopia and full color blindness, so you can spot colors that become hard to tell apart.
